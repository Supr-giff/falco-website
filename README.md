# Falco Football Website⚽

Football club website building with React + TypeScript (Vite) and NestJS. Technology stack will be updated in the future accordingly.

# Requirements

Install Git and Node.js (Node.js 22 recommended).

# Clone and install 

`git clone https://github.com/Supr-giff/falco-website.git` <br>
`cd falco-website` <br>
`cd falco-frontend` <br>
`npm install` <br>
`cd ../falco-backend` <br>
`npm install`

<i> Run locally </i>

# Open two terminals in the project root.

## Terminal 1 — Backend:

`cd falco-backend` <br>
`npm run start:dev`

Backend: http://localhost:3000 — Test: http://localhost:3000/api/hello

## Terminal 2 — Frontend:

`cd falco-frontend` <br>
`npm run dev`

Frontend: http://localhost:5173 (or the URL shown by Vite).

Keep both terminals running. The frontend currently expects the backend at http://localhost:3000.
